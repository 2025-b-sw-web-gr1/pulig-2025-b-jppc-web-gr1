Documentación de Endpoints con Swagger (OpenAPI)

📝 Descripción:

API RESTful de Equipos y Jugadores documentada automáticamente con Swagger, basada en NestJS + TypeORM + SQLite

📚 API Documentation (Swagger) 🔗 OpenAPI JSON

📋 Endpoints Disponibles

Teams (Equipos)

GET /teams
GET /teams/:id
GET /teams/:id/players
POST /teams
PUT /teams/:id
DELETE /teams/:id

Players (Jugadores)

GET /players
GET /players/:id
POST /players
PUT /players/:id
DELETE /players/:id
